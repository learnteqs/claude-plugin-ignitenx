# SOP Document Templates

## Standard SOP Template

```
STANDARD OPERATING PROCEDURE

Document No: SOP-[DEPT]-[NUMBER]
Version: [VERSION]
Effective Date: [DATE]
Review Date: [DATE + 1 YEAR]

Title: [SOP TITLE]

1. PURPOSE
   [Brief description of why this SOP exists and what it aims to achieve]

2. SCOPE
   [Who and what this SOP applies to — departments, roles, processes]

3. DEFINITIONS & ABBREVIATIONS
   - [Term]: [Definition]

4. RESPONSIBILITIES
   | Role | Responsibility |
   |------|----------------|
   | [Role] | [What they must do] |

5. PROCEDURE
   5.1 [Step Category]
       5.1.1 [Detailed step]
       5.1.2 [Detailed step]
   5.2 [Step Category]
       5.2.1 [Detailed step]

6. SAFETY PRECAUTIONS (if applicable)
   - [Safety note]

7. REFERENCES
   - [Related documents, standards, regulations]

8. REVISION HISTORY
   | Version | Date | Author | Changes |
   |---------|------|--------|---------|
   | 1.0 | [DATE] | [NAME] | Initial release |

Prepared by: _______________  Date: _______________
Approved by: _______________  Date: _______________
```

## Template Variations

### Safety SOP
- Add "HAZARDS AND RISK ASSESSMENT" section after Section 4
- Add "EMERGENCY PROCEDURES" section
- Include PPE requirements checklist
- Add incident reporting procedure

### Process/Operational SOP
- Include process flow diagram
- Add quality checkpoints
- Include troubleshooting guide
- Add performance metrics/KPIs

### Onboarding SOP
- Include welcome/orientation checklist
- Add IT setup requirements
- Include day-by-day schedule (Week 1, Week 2, etc.)
- Add mentor assignment section

### Compliance SOP
- Add regulatory reference section
- Include audit trail requirements
- Add certification/attestation section
- Include non-compliance consequences

## Formatting Guidelines

- Use clear, action-oriented language ("Do X", not "X should be done")
- Keep steps numbered and sequential
- Use tables for structured information
- Include diagrams/screenshots where helpful
- Use consistent terminology throughout
- Keep sentences under 25 words where possible
